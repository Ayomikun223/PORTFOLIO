## What I changed
- Added a theme toggle component (light/dark) that persists the user's preference.
- Added a Resume placeholder and a Resume section to the site.
- Updated README with deployment instructions for Vercel.

## Local development
1. Install dependencies

```bash
npm install
```

2. Run development server

```bash
npm run dev
```

3. Open http://localhost:3000

## Deploying to Vercel (recommended)
1. Go to https://vercel.com/new and connect your GitHub account.
2. Import the `Ayomikun223/PORTFOLIO` project.
3. Vercel auto-detects Next.js — the defaults should work. Deploy.

When you have a resume PDF, upload it to `/public/resume.pdf` in this repo. The site links to `/resume.pdf` from the Resume section.
